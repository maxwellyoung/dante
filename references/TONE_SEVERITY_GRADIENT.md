# The severity gradient — serious destinations, unserious roads

Maxwell, 2026-07-05: "one interesting thing to draw from Firewatch and Monkey
Island is the severity in the jokes — the story beat is important but how you
get there is less serious."

## The principle

**Story beats carry full weight. Traversal between them carries play.**
- Firewatch: the road is Turt Reynolds, naked teens, a stolen boombox, "I'm
  still holding it." The destinations — Brian Goodwin's cave, the ending — are
  played completely straight. The comedy BUYS the gravity: you trust the game
  isn't manipulating you because it was just goofing with you.
- Monkey Island: the path is rubber-chicken absurdism; Guybrush's want and
  LeChuck's menace are real. Puzzle silliness never bleeds into beat scenes.
- Gravity Bone: a comedy right up until the second it isn't. The cut does
  the severity switch.
- Remo names the mechanism: the extra rations day was "played more for a joke
  than anything else" — cheap, reactive, character-deepening. Jokes are the
  cheapest reactive content there is (a few lines, no new systems).

## The gradient, applied to EV

Comedy density is a function of position on the spine:
- **Lobby / corridor / glasshouse / suite props** (the road): Gibbons'
  deadpan, thermostat fiddling, the ashtray, room service jokes — Puzzle
  Agent register, Bolaño politeness. ADD MORE HERE; it's cheap.
- **Photograph, adjoining door, wineglass** (mid-weight): wry but tender.
  One step down from jokes.
- **Bed / stars / dream / montage** (destinations): zero jokes. Not one.
  The register break IS the beat.

Rule of thumb for writers: if the player can walk away from it, it can be
funny. If the game takes control (cut, ending, dream), it cannot.

## Applied to AFTERSHOW

Same gradient: the forum threads and Green Room prop memories can be funny
(podcast in-jokes, username comedy); the exhibits' FILE cards stay procedural
-deadpan; the fourth chair and both endings are played dead straight.
